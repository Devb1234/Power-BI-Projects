# 💼 Sales Analytics Dashboard with Power BI

This project showcases a robust **sales analytics dashboard** using Power BI. It integrates orders and product details to provide deep insights into revenue, customer behavior, and performance trends.

---

### 📌 Project Description

Effective sales monitoring is vital for business growth. This project turns raw sales data into meaningful visuals through Power BI, empowering stakeholders to make data-driven decisions across orders, customers, and products.

---

### 📁 Dataset

* **Files**:
  - `Orders.csv`: Contains order-level information such as customer, date, and order status.
  - `Details.csv`: Contains line-item details like product, quantity, and price.

* **Format**: CSV (Comma-Separated Values)  
* **Combined Metrics**:

  * Order ID, Customer Name, Order Date
  * Product, Unit Price, Quantity
  * Total Revenue, Discounts, Category

---

### 📊 Key Insights & Visualizations

The Power BI dashboard (`Dashboard.pbix`) includes:

* **Revenue Trends**: Month-wise sales and growth
* **Top Products**: High-performing items by revenue
* **Category Analysis**: Compare product categories by volume
* **Customer Segments**: Insights by region, order frequency
* **KPIs**: Total Sales, Orders, Average Order Value

---

### 🛠️ How to Use

1. Open `Dashboard.pbix` in Power BI Desktop  
2. If prompted, update the CSV file paths for `Orders.csv` and `Details.csv`  
3. Click "Refresh" to update visuals  
4. Use slicers and filters to interact with the data
