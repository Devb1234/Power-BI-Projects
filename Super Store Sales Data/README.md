# 🛒 Super Store Sales Dashboard & Forecasting (Power BI)

This project presents an interactive **Power BI dashboard and sales forecasting** solution based on the Superstore dataset. It provides key insights into regional sales trends, product performance, and future sales predictions.

---

### 📌 Project Description

Retail businesses need to track KPIs, understand market behavior, and forecast demand. This project uses Power BI to analyze Superstore sales data and apply time-series forecasting to assist in inventory and financial planning.

---

### 📁 Dataset

* **File**: `SuperStore_Sales_Dataset.csv`  
* **Format**: CSV (Comma-Separated Values)  
* **Data Includes**:
  * Order ID, Product Name, Category, Sub-Category
  * Sales, Profit, Quantity, Discount
  * Order Date, Ship Mode, Region, Customer Segment

---

### 📊 Key Visuals in Power BI

The `Dashboard and Sales Forecast.pbix` includes:

* 📈 **Sales Forecasting**: Line chart predictions using built-in analytics  
* 📍 **Region-wise Sales**: Geographical maps and filters  
* 🎯 **Top Products & Categories**: Based on Sales and Profit  
* ⏳ **Time Series Trends**: Monthly sales performance  
* 💰 **KPI Cards**: Total Sales, Profit, Quantity Sold, Discounts  

---

### 🛠️ How to Use

1. Open `Dashboard and Sales Forecast.pbix` in Power BI Desktop  
2. Update the data source path if needed (for `SuperStore_Sales_Dataset.csv`)  
3. Refresh data to apply all calculations and visuals  
4. Use slicers (Region, Category, Date) to interact dynamically
