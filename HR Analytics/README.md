# 👥 HR Analytics Dashboard with Power BI

This project delivers a comprehensive **HR analytics dashboard** using Power BI. It offers insights into employee satisfaction, attrition, promotion trends, and other HR metrics to support data-driven HR decisions.

---

### 📌 Project Description

Employee data is a goldmine for improving organizational efficiency. This project utilizes structured HR data to build an interactive dashboard that helps HR teams analyze key trends, identify red flags, and understand workforce dynamics.

---

### 📁 Dataset

* **File**: `HR_Analytics.csv`  
* **Format**: CSV (Comma Separated Values)  
* **Data Includes**:

  * Department & Region
  * Education and Gender
  * Recruitment channel
  * No. of trainings and last evaluation scores
  * Awards won, average training score
  * Length of service and attrition status

---

### 📊 Key Insights & Visualizations

Built in `Dashboard.pbix`, the Power BI report includes:

* **Attrition Analysis**: Identify patterns among employees who left
* **Training Impact**: Correlation between training and performance
* **Department-wise Trends**: Analyze metrics across business units
* **Demographics**: Education level, gender, and recruitment source impact
* **KPI Cards**: Quick overview of active employees, attrition rate, average training score

---

### 🛠️ How to Use

1. Open `Dashboard.pbix` in Power BI Desktop  
2. If prompted, update the CSV file path for `HR_Analytics.csv`  
3. Refresh the data  
4. Interact with filters and slicers to explore data dimensions
